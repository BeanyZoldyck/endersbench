## Verifier and ownership
Implementation worker may modify only its assigned frontend files and entry wiring. Coordinator owns new verifier tests and browser checks; worker must not modify verifier tests or weaken existing checks. Deterministic gates: npm test, npm run build, npm run test:module (where dependency requirements permit), plus locked studio regression tests. Independent integration review resolves material findings.

## Loop protocol and stop rules
Trigger: an implementation submission or a failing check. Inspect output, make a focused correction, rerun the affected check. At most five correction iterations per defect; the same failure twice triggers diagnosis/escalation rather than repeating the action. Stop when all acceptance units pass. Missing permissions or external runtime only block dependent checks; never label unverified live service behavior as tested. Log outcomes below and in HANDOFF-OBSERVATION-STUDIO.md. Do not install new packages, access secrets, mutate live services, publish, or push without authorization. Existing locked npm dependencies were explicitly approved.
